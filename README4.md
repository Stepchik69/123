# Различие между задачей о рюкзаке и 0-1 рюкзаком

## Основное принципиальное различие

**Фундаментальное отличие** заключается в **кратности использования предметов**:

### Задача о рюкзаке (Unbounded Knapsack)
- Каждый тип предмета можно брать **неограниченное количество раз**
- Можно использовать один и тот же предмет многократно
- Пример: если есть золотые слитки одного типа, можно взять несколько таких слитков

### Задача о 0-1 рюкзаке (0-1 Knapsack)
- Каждый предмет можно использовать **только один раз**
- Решение для каждого предмета: либо взять (1), либо не брать (0)
- Пример: уникальные произведения искусства - каждый экземпляр единственный

## Математическая формулировка различий

**Для обычного рюкзака:**
- Переменные решения: целые неотрицательные числа
- Каждая переменная показывает, сколько раз взят предмет данного типа
- Ограничение: xᵢ ≥ 0 и целое

**Для 0-1 рюкзака:**
- Переменные решения: бинарные (0 или 1)
- Каждая переменная показывает, берем ли мы предмет
- Ограничение: xᵢ ∈ {0, 1}

## Практические примеры различий

### Сценарий 1: Упаковка чемодана
- **0-1 рюкзак**: Каждая вещь уникальна - один свитер, одна пара обуви
- **Обычный рюкзак**: Можно взять несколько одинаковых предметов - несколько пар носков, несколько футболок

### Сценарий 2: Инвестиции
- **0-1 рюкзак**: Выбор уникальных проектов для инвестирования
- **Обычный рюкзак**: Покупка акций одного типа в любом количестве

## Последствия различия для решения

### Вычислительная сложность
Обе задачи являются NP-трудными, но подходы к их решению различаются:

- В **0-1 рюкзаке** перебор всех комбинаций требует рассмотрения 2ⁿ вариантов
- В **обычном рюкзаке** теоретически бесконечное число комбинаций, но на практике ограничено вместимостью

### Стратегия решения
- Для **0-1 рюкзака** часто используется динамическое программирование с таблицей решений
- Для **обычного рюкзака** также применяется динамическое программирование, но с другой логикой заполнения таблицы

## Особенности оптимального решения

**В 0-1 рюкзаке:**
- Оптимальное решение может не включать предметы с высокой удельной стоимостью, если они не "вписываются" в оставшееся пространство
- Каждый предмет рассматривается индивидуально

**В обычном рюкзаке:**
- Часто оптимально брать предмет с максимальной удельной стоимостью (стоимость/вес) до тех пор, пока это возможно
- Можно полностью заполнить рюкзак лучшим предметом, если это выгодно

## Области применения

**0-1 рюкзак применяется когда:**
- Ресурсы уникальны и неделимы
- Проекты исключают друг друга
- Предметы существуют в единственном экземпляре

**Обычный рюкзак применяется когда:**
- Ресурсы тиражируемы и взаимозаменяемы
- Можно использовать несколько единиц одного ресурса
- Предметы доступны в неограниченном количестве

Это фундаментальное различие определяет не только математическую формулировку задач, но и подходы к их решению, а также области практического применения.
